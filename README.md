# Sahib Truck & Trailer Repair — Static Website

Static clone/package based on the supplied saved website page.

## Files

- `index.html` — complete website markup and content
- `style.css` — compiled styling plus local static-site fixes
- `script.js` — mobile navigation, smooth scrolling, and static contact-form handling
- `CNAME` — custom GitHub Pages domain
- `README.md` — this file

## GitHub Pages

1. Upload all five files to the root of your GitHub repository.
2. Enable **Settings → Pages** and deploy from the main branch/root.
3. GitHub Pages will use the `CNAME` file for the custom domain.
4. At your domain registrar, point DNS to GitHub Pages as instructed by GitHub.

## Domain

`sahibtruckandtrailerrepair.com`

## Contact form

Because this is a static site with no backend, the request form opens the visitor's email client and sends the request to:

`info.sahibtruck@gmail.com`

## Notes

The original saved page contained a Netlify preview/management toolbar. That toolbar was removed from this static package so it will not appear on your live domain.
